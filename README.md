# 曲中剑网页展示原型

一个以「曲中剑」为主题的静态游戏介绍页，包含水墨粒子背景、滚动入场动画、移动导航、玩法介绍、音乐展示和下载区域。

仓库沿用 `QZJ-Downloader` 名称，当前保存的是网页展示代码，并未实现下载器引擎或游戏客户端。

## 运行

直接打开 `index.html`，或在仓库目录运行：

```sh
python -m http.server 8000
```

访问 `http://localhost:8000`。页面使用 Google Fonts，外部字体加载需要网络。

## 文件

- `index.html`：页面结构与展示内容。
- `style.css`：布局、配色及动效样式。
- `script.js`：粒子背景、导航与页面交互。

## 项目状态

这是静态展示原型。下载按钮目前使用占位链接，二维码为展示内容，没有可下载的正式发行包。原始源码最后修改于 2026-07-21；后续备份及文档提交不代表功能继续开发。
